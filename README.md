## Публикация на GitHub Pages за 5 минут

1. **Создайте репозиторий.** Зайдите на [github.com/new](https://github.com/new), имя — например `yug-region-site`, тип — **Public**, галочку «Add a README» **не ставьте**. Нажмите *Create repository*.
2. **Загрузите файлы.** На странице пустого репозитория — ссылка *uploading an existing file*. Перетащите туда `index.html`, `.nojekyll`, `README.md` и **папку `images` целиком** (с фотографиями). Нажмите *Commit changes*.
   - Важно: `index.html` должен лежать в **корне** репозитория, а не в подпапке. Иначе сайт не откроется.
3. **Включите Pages.** *Settings* → слева *Pages* → в блоке **Build and deployment**: *Source* = **Deploy from a branch**, *Branch* = **main**, папка = **/ (root)** → *Save*.
4. **Подождите 1–2 минуты** и обновите страницу — сверху появится ссылка вида
   `https://ВАШ-ЛОГИН.github.io/yug-region-site/`. Это и есть адрес сайта.
5. **Проверьте на телефоне.** Откройте ссылку с мобильного: должны работать кнопки «Позвонить», «Заказать расчёт» и фото в карточках техники.

### Обновление сайта
Меняете `index.html` прямо на GitHub (карандаш → *Commit changes*) или загружаете файл заново. Новая версия появится на сайте через 1–2 минуты.

## Карта: как вставить свою

Сейчас в блоке «Контакты» стоит стандартный виджет Яндекс Карт по адресу компании.

1. Откройте [Яндекс Конструктор карт](https://yandex.ru/map-constructor/).
2. Найдите «Краснодар, улица Пашковский Перекат, 2/1», поставьте метку на нужное здание.
3. Нажмите **«Получить код карты»** → скопируйте готовый `<iframe>`.
4. В `index.html` найдите блок `<!-- ================= КОНТАКТЫ =================` и замените `<iframe ...></iframe>` целиком на скопированный.
5. Высота карты — 300 px. Оставьте у своего `<iframe>` атрибуты `loading="lazy"`, `width="100%"`, `height="300"` (либо поправьте `.map iframe` в `<style>`).

## Микроразметка JSON-LD (для Google и Яндекса)

Блок `<script type="application/ld+json">` находится в конце страницы, перед `</body>`, в `index.html`.

Что стоит проверить и поправить:

- `telephone` — формат `+7-989-810-00-41` (без пробелов и скобок);
- `address` → `streetAddress`, `addressLocality` (город), `addressRegion`, `addressCountry` (`RU`);
- `priceRange` — вилка цен, например `от 1800 ₽/час`;
- если появится домен, добавьте `"url": "https://ваш-домен.ru/"`.

Если поставите на карте точные координаты здания, добавьте рядом с `address`:

```json
"geo": { "@type": "GeoCoordinates", "latitude": 45.0355, "longitude": 38.9753 }
```

(координаты замените на свои — возьмите из Яндекс Карт: правый клик по метке → «Что здесь?»).

Проверить разметку: [validator.schema.org](https://validator.schema.org/) или [Яндекс Вебмастер → Валидатор микроразметки](https://webmaster.yandex.ru/tools/microtest/).

## Свой домен (если появится)

1. Купите домен у любого регистратора (reg.ru, Timeweb, Beget).
2. В репозитории: *Settings* → *Pages* → **Custom domain** → впишите домен (например `yug-region.ru`) → *Save*.
3. У регистратора в DNS создайте записи:
   - `A` для `@` → `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
   - `CNAME` для `www` → `ВАШ-ЛОГИН.github.io`
4. Дождитесь выпуска сертификата (в Pages появится галочка **Enforce HTTPS**) и включите её.

Актуальные IP-адреса GitHub Pages всегда можно посмотреть в [официальной документации](https://docs.github.com/pages/configuring-a-custom-domain-for-your-github-pages-site).

## Что поменять перед публикацией

- **Цены** — сейчас указаны ориентировочные (`от 2 200 ₽/час` и т. д.), в разделе «Услуги и цены».
- **Телефон** — встречается в шапке, hero, контактах, подвале и в ссылках `tel:`. Меняйте все вхождения сразу (Ctrl+H в редакторе).
- **Telegram** — сейчас стоит `https://t.me/` (без вашего ника). Замените на `https://t.me/ВАШ_НИК` — ссылка встречается в 2 местах: кнопка в hero и блок «Контакты».
- **MAX** — сейчас стоит `https://max.ru/`. Возьмите ссылку на свой профиль (приложение MAX → Профиль → «Поделиться» → скопировать ссылку) и замените тоже в 2 местах.
- **Фото** — 7 файлов в `images/` (см. таблицу выше). Меняете снимок — сохраняйте его под тем же именем, иначе карточка останется пустой.
